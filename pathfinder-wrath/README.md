# Pathfinder: Wrath of the Righteous

Two playthroughs live here. Each has its own GameId, and the game loads the mod config for the save you open.

- [FaN lich](./lich/README.md) — Wrath Tactics, Buff It, Kestoglyr and the horse build, and the FaN save snapshot.
- [Hansen angel](./angel-hansen/BuffIt-OneClickBuff.md) — Buff It for the Inevitable Excess angel party.

`tools/refresh_current_snapshot.cmd` updates the FaN snapshot in `lich/current/`. It reads only FaN's GameId, `7ea3d466491c4249aec2742271c2e71a`.

Start the game yourself. After you finish a FaN session, double-click that script.
