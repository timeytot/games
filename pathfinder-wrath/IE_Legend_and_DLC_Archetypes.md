# Inevitable Excess Legend and DLC5 / DLC6 Archetypes

General reference. No character-specific data.

## Inevitable Excess: Legend rules

IE new characters use a **special Legend entry**:

- Pick **Legend at Mythic Rank 3** during path select.
- The character starts as **level 40 / mythic rank 3**.
- You **cannot** play Angel / Lich / Trickster (or any other path) first and then convert to Legend at MR8 the way the main campaign does.

Main-campaign Legend (MR8) strips most MR3–8 mythic abilities, feats, and merged spellbooks. That conversion path does **not** apply to IE new-character Legend.

Sources:

- [GameFAQs — IE postlude / starting ranks](https://gamefaqs.gamespot.com/ps4/324475-pathfinder-wrath-of-the-righteous/faqs/80843/postlude-inevitable-excess)
- [Steam — IE Legend only at MR3, not MR8 convert](https://steamcommunity.com/app/1184370/discussions/0/4031346570751578331/)

**Do not** import main-campaign plans that need Azata→Devil, Trickster→Gold Dragon, or Angel/Lich merged books **then** Legend into an IE **new Legend** run.

## DLC6: A Dance of Masks

Owlcat added 11 new archetypes ([official news](https://wrath.owlcat.games/news/78)).

Neoseeker-style combat ranking (approximate):

| Grade | Archetype |
|---|---|
| **SS** | Inciter (Skald), Kinetic Sharpshooter (Kineticist) |
| **S** | Sable Company Marine (Ranger) |
| **A−** | Drunken Master (Monk), Titan Fighter (Fighter) |
| **B+** | Bloodseeker (Slayer), Mantis Zealot (Warpriest) |
| **B** | Magic Deceiver (Arcanist) |
| **C+** | Bladebound (Magus) |
| **C** | Chelaxian Diva (Bard), Living Grimoire (Inquisitor) |

### IE-friendly priorities (DLC6)

1. **Kinetic Sharpshooter 19 / Fighter 1** — ranged; almost path-agnostic; works on IE Legend. [Wenduag kinetic archer (DLC6)](https://www.neoseeker.com/pathfinder-wrath-of-the-righteous/builds/Kinetic_Archer_Wenduag_%28DLC6%29)
2. **Sable Company Marine 1** into Sohei / Gendarme / Mutation Warrior — flying mount and charge; strong Unfair early pick. [Reddit discussion](https://www.reddit.com/r/Pathfinder_Kingmaker/comments/1lwoabt/strongest_dlc_archetypes_for_unfair_dance_of/)
3. **Inciter Skald 20** — party melee buffer; better as a merc; watch capstone/skill bugs. [Skald merc (DLC6)](https://www.neoseeker.com/pathfinder-wrath-of-the-righteous/builds/Skald_Mercenary_%28DLC6%29)
4. **Drunken Master 20** — strong pure martial in high-level IE; needs a Shield source (BFT, alchemist, scrolls).

Prima Games ranks novelty/impression differently (Bladebound first, Inciter near last): [Prima ranking](https://primagames.com/gaming/best-new-archetypes-in-pathfinder-wotr-dance-of-masks-ranked). That is not the same as Neoseeker combat min-max grades.

## DLC5: The Lord of Nothing

Owlcat added 15 archetypes usable in the main campaign ([official news](https://wrath.owlcat.games/news/75)).

Neoseeker-style ranking (approximate):

| Grade | Archetype |
|---|---|
| **S** | Ghost Rider, Weretouched, Geomancer |
| **A+** | Winter Child, Shadowcaster, Dual-Cursed Oracle |
| **A−** | Tandem Executioner |
| **B+** | Hag of Gyronna |
| **B** | Dark Lurker |
| **B−** | Hag-Riven, Tortured Crusader |
| **C+** | Prophet of Pestilence |
| **C** | Reanimator, Flesheater |
| **D** | Separatist |

Useful documented builds:

- **Burning Ember** — Stigmatized Witch 10 / Geomancer 1 / Loremaster 9 (Unfair viable). [Build](https://www.neoseeker.com/pathfinder-wrath-of-the-righteous/builds/Burning_Ember_%28DLC5%29)
- **Weretouched shifter** — Shifter 17 / Witch 1 / Fighter 1 / Demonslayer 1 (Unfair viable); Demon trip loops need Demon path (not IE new Legend). [Demonic Shifter](https://www.neoseeker.com/pathfinder-wrath-of-the-righteous/builds/Demonic_Shifter)
- **Ghost Rider riding Vivisectionist** — mount / pet / melee package. [Riding Vivi](https://www.neoseeker.com/pathfinder-wrath-of-the-righteous/builds/Riding_Vivi_Mercenary)
- **Dual-Cursed Oracle** — top DLC5 Oracle; Angel merge is main-campaign, not IE new Legend. [Reddit](https://www.reddit.com/r/Pathfinder_Kingmaker/comments/1lwoabt/strongest_dlc_archetypes_for_unfair_dance_of/)

Standalone Lord of Nothing only reaches roughly level ~11 with thorough play ([GameFAQs LoN](https://gamefaqs.gamespot.com/ps4/324475-pathfinder-wrath-of-the-righteous/faqs/80843/interlude-the-lord-of-nothing)). Most “DLC5 builds” online are **archetypes used in the main campaign**, not the standalone level band.

| Melee party | Inciter Skald merc + Sable Company Marine 1 on a charger |
