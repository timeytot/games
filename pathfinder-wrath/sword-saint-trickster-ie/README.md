# Sword Saint / Trickster / Intelligence Heavy Pick

This is the all-DLC direct-entry Inevitable Excess solo-PvP build. It does not use the main-campaign Trickster-to-Legend conversion route and does not inherit Trickster feats into Legend. The main route assumes Lord of Nothing is installed, so Stunning Critical is available.

The verified level-20 finish is **Human Sword Saint 20 / Trickster MR10**, INT level-ups, Death's Consonant Heavy Pick, empty off-hand, **Luck + Travel** domains, **Stunning Critical** at the late Sword Saint bonus slot, and **Greater Weapon Specialization (Heavy Pick)** at level 19. The route does not spend feats on Staggering Critical or Critical Mastery.
