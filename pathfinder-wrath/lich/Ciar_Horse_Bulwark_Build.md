# Ciar Horse Bulwark Tank Build

This file is a build plan, not a save diagnostic.

Goal: make Ciar's Horse the party's second front line. The job is not damage. The horse should:

- take the first wave of melee attacks
- share the targets that would otherwise hit Ciar
- raise AC, DR, Will, and resistance to control
- stand with Kestoglyr as a second tank

## Animal Companion Archetype

Bulwark.

Automatic Bulwark growth:

| Level | Gains |
|---:|---|
| 1 | Armor Proficiency (Light Barding), DR 2/- |
| 4 | DR 3/- |
| 6 | Devotion |
| 8 | DR 4/- |
| 9 | Armor Proficiency (Medium Barding) |
| 12 | DR 5/- |
| 16 | DR 6/- |
| 20 | DR 7/- |

## Ability Score Increases

Level 4: INT +1. Raise Horse INT from 2 to 3 so later combat feats and the Crane Style line are available.

After that, every increase goes to DEX:

| Level | Increase |
|---:|---|
| 4 | INT +1 |
| 8 | DEX +1 |
| 12 | DEX +1 |
| 16 | DEX +1 |
| 20 | DEX +1 |

## Skills

Mobility needs at least 3 ranks. After rank 3, do not keep spending points on Mobility for this build.

Later priority:

1. Perception
2. Athletics

When a level has spare points, raise Perception first, then Athletics.

## Combat Toggles

Leave these on:

- Crane Style
- Fighting Defensively

The horse is there to defend, not to maximize attack.

## Equipment / Barding

Bulwark grants Light Barding proficiency, then Medium Barding proficiency at level 9.

Do not assume a barding piece is better just because it can be worn. For each new horse barding:

1. Equip it.
2. Read the actual AC.
3. Compare it with AC while wearing no barding.
4. Keep the set with the higher AC.

At high DEX, a barding Max Dexterity cap can lower total AC.

## Rider Synergy

If the horse is Ciar's mount, Ciar should have Mounted Shield. Mounted Shield improves the mount's defense.

This file only records that dependency. It does not change Ciar's build. A Ciar change needs its own plan.

## Buff Priorities

Keep these on the horse when they apply:

- Shield of Faith
- Barkskin
- Haste
- Freedom of Movement
- Death Ward
- Blessing of Unlife, if the party's negative-energy setup still needs it
- Animal Growth, judged per fight

If a buff uses the same bonus type as a worn item, trust the AC breakdown in game.

## Party Role

- Kestoglyr: main tank
- Ciar + Horse: second tank / second line
- Staunton: supporting melee
- Galfrey: control and Inspire Heroics
- Delamere: main ranged damage
- Skeletal Marksman: ranged support
- FaN: lich control, Corrupt Magic, Hungry Flesh, Pit, Restore Undead

The horse does not run into the middle of a crowd. Preferred order from the enemy backward:

1. Kestoglyr / Horse
2. Ciar / Staunton
3. Galfrey / FaN
4. Delamere / Skeletal Marksman
